This project is a simple and clean Netflix UI Clone built using HTML, CSS, and JavaScript.
It replicates the basic look and feel of Netflix’s homepage, including banners, sections, and layout styling.

🚀 Features

🎬 Netflix-style Homepage UI
📂 Movie & show sections layout (Trending, Popular, etc.)
🎥 Background banner with title and overview text
📱 Fully responsive design for mobile, tablet & desktop
🔤 Custom fonts and Netflix-inspired color theme
🎞 Smooth hover effects and transitions
🖼 Image assets organized in folders

🛠 Tech Stack

HTML5
CSS3
JavaScript
Images, icons & media files

📁 Project Structure

/images
/index.html
/style.css
/sty1.css
/video files
/extra html files

🎯 What I Learned

Structuring a real-world UI using only HTML & CSS
Working with grids, flexbox, and responsive layouts
Creating Netflix-inspired theme and animations
Organizing a front-end project and assets
